# 사용자 가이드

영상 주소(URL)를 입력하면 yt-dlp 로 영상을 가져와 원하는 구간만 잘라 저장하는 Windows Electron 앱.

## 설치

[Releases](https://github.com/OhSorry-DP/streamcut/releases) 에서 Windows용 파일을 받는다.

- `StreamCut-<버전>-win-x64.exe` — 설치형(설치 위치 선택 가능)
- `StreamCut-<버전>-portable.exe` — 설치 없이 바로 실행

0.5.0부터 표시 이름은 `Stream Cut`이다. 기존 설정·대기열과 관리 도구를 계속 사용하도록 데이터 폴더는 `%APPDATA%\YT Cut`으로 유지한다. 기본 출력 폴더도 `Videos/ytcut`으로 유지한다.

코드 서명이 없어서 처음 실행하면 Windows SmartScreen 경고가 뜰 수 있다(「추가 정보」→「실행」).
`yt-dlp` 와 `ffmpeg` 는 포함되어 있지 않다. `ffmpeg` 는 따로 설치해 PATH 에 두어야 하고, `yt-dlp` 는 없거나 오래되면 앱이 최신 버전을 자동으로 받아 둔다(아래 요구 사항).

설치형은 새 버전이 나오면 앱 안에서 알려 주고 업데이트한다. **0.4.0 부터** 자동 업데이트가 들어 있어서, 0.3.0 이하를 쓰고 있다면 한 번만 직접 설치해야 한다.

## 사용법

1. 앱을 실행한다(소스에서는 `npm install` 후 `npm start`).
2. 영상 주소를 넣고 「불러오기」 — 앱 안 플레이어에 영상이 뜬다.
3. 플레이어 아래 타임라인에서 시작/끝 핸들을 끌거나 시간을 직접 입력해 구간을 정한다.
   - 타임라인 아무 곳이나 클릭하면 그 지점으로 이동해 재생한다.
   - 단축키: Space 재생/정지, ←/→ 10초, Ctrl+←/→ 1초, I/O 현재 시각을 시작/끝으로 지정, P 시작점부터 미리 재생.
   - `Ctrl` + 휠로 확대/축소, 가로 스크롤로 이동.
4. 내보내기 형식(MP4 기본 / MKV)과 자르기 모드(정확하게 / 빠르게)를 고른다. 「다운로드」 옆 파일명 입력에는 확장자를 제외한 이름을 넣는다. 비우면 영상 제목의 금지 문자를 치환·정제한 이름으로 저장한다. 「다운로드」를 누르면 설정의 출력 폴더 바로 아래에 최종 파일이 저장되며, 같은 이름이 있으면 ` (2)`, ` (3)` 이 붙는다. 기존 대기열 항목은 이전 중첩 저장 위치를 유지한다.
5. 오른쪽 사이드패널의 다운로드 대기열에 항목이 생기고 바로 시작된다. 진행 중에도 새 구간을 잡아 계속 추가할 수 있다.
   - 큐 항목을 누르면 그때의 영상·구간·확대·스크롤·형식이 그대로 복원된다.
   - 행에 마우스를 올리면 아이콘 버튼(파일명 변경 / 폴더 열기 / 파일 열기 / 파일 삭제 / 목록에서 제거 / 취소 / 재시도)이 나타난다. 큐는 앱을 껐다 켜도 유지된다.
   - 연필 아이콘으로 이름을 편집하고 Enter 로 확정, Esc 로 취소한다. 다운로드 중에는 이름을 바꿀 수 없다. 완료 항목은 디스크 파일도 함께 개명하며, 파일 개명이 실패하면 앱 이름도 바뀌지 않는다. 큐 저장이 실패하면 원래 파일명으로 복구를 시도한다.
   - 탐색기에서 완료 파일을 지우면 「삭제된 파일」로 표시한다. 앱 시작·창 포커스·대기열 목록에 마우스를 올릴 때 파일 존재 여부를 확인한다. 같은 위치로 파일을 복구하면 정상 표시로 돌아온다.
6. 설정은 헤더 오른쪽 톱니 버튼 → 모달(일반 / 도구 / 앱 업데이트).

## 요구 사항

- `yt-dlp`, `ffmpeg` — PATH에 있거나 설정에서 경로를 지정한다. 경로를 기본값으로 두면 yt-dlp 는 자동 업데이트되며, 직접 지정한 경로는 건드리지 않는다.
- MP4는 H.264/AAC 스트림만 골라 담는다. 해당 스트림이 없는 영상(예: VP9 전용 고해상도)은 실패하므로 그때는 MKV를 쓴다.
- 일반 설정의 「미리보기 해상도」에서 360p/480p/720p 상한을 선택한다(기본 480p). 미리보기에만 적용, 다운로드 화질과 무관하며, 상한 이하 AVC 스트림 중 가장 높은 화질을 사용한다. 480p가 없으면 360p 등 하위 화질을 사용하며 강제로 업스케일하지 않는다.
- 「항상 대체 플레이어 사용」은 기본으로 켜져 있다. 영상 정보 조회 후 대체 플레이어를 바로 사용하며 「대체 플레이어」 배지가 표시된다. 끄면 임베드 플레이어(iframe)를 먼저 사용하고 임베드 오류 101/150/153에서 대체 플레이어로 전환한다(153을 영상 소유자의 차단으로 단정하지 않는다).
- 대체 플레이어 준비 또는 재생에 실패하면 임베드 플레이어(iframe)로 한 번 전환한다. 전환된 플레이어도 실패하면 미리보기만 비활성화하며, 숫자 입력으로 구간을 편집하고 다운로드할 수 있다.
- 설정 저장은 현재 재생을 재시작하지 않는다. 다음 영상 로드·재로드·대기열 클릭 또는 Enter/Space 복원부터 최신 미리보기 설정을 사용한다. 대기열의 구간·재생 위치·형식·파일명은 유지된다.
- 대체 플레이어는 MSE 로 앞쪽 약 180초·뒤쪽 60초의 버퍼를 유지한다. 받은 범위 안의 ±10초 이동과 연타는 스트림을 다시 열지 않고 즉시 처리하며, 범위 밖 이동은 새 스트림을 연다. 사용자 제공 실측에서는 처음 로드가 약 9.1초에서 4.1초로, 버퍼 안 ±10초 이동은 약 0.04초로 개선되었다. 실제 대기 시간은 영상과 환경에 따라 달라진다.
- (개발) Node.js, Electron 44.7.0 — 자세한 건 [dev-guide.md](dev-guide.md).

## 면책조항

이 앱은 **스트리머 본인이 소유한 본인의 영상을 백업하는 용도**로 제작되었다.
본인이 권리를 가진 영상에만 사용해야 한다. 타인의 저작물을 무단으로 내려받거나 배포하는 데 사용하면 안 된다. 그로 인해 발생하는 문제의 책임은 사용자에게 있다.
