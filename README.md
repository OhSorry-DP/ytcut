# Stream Cut

영상 주소(URL)를 입력하면 yt-dlp 로 영상을 가져와 원하는 구간만 잘라 저장하는 Windows Electron 앱입니다. 영상 주소를 넣고 타임라인에서 시작/끝을 고르면, yt-dlp 와 ffmpeg 가 그 구간만 MP4/MKV 로 저장합니다.

- 다운로드: [Releases](https://github.com/OhSorry-DP/streamcut/releases)
- 문서(설치·사용법, 변경 이력, 구조, 개발 가이드): [docs/](docs/README.md)

## 면책조항

이 앱은 **스트리머 본인이 소유한 본인의 영상을 백업하는 용도**로 제작되었다.
본인이 권리를 가진 영상에만 사용해야 한다. 타인의 저작물을 무단으로 내려받거나 배포하는 데 사용하면 안 된다. 그로 인해 발생하는 문제의 책임은 사용자에게 있다.

## 변경 이력

### 0.5.0 — 이름 변경(Stream Cut)
- 표시 이름·저장소·설치 파일명을 변경했습니다. 기존 앱 식별자와 데이터 폴더를 유지하며 업데이트 URL을 새 저장소로 바꿨습니다. 자세한 내용은 [변경 이력](docs/changelog.md)을 참고하세요.

### 미출시 — 미리보기 설정과 플레이어 전환
- 미리보기 해상도 상한을 360/480/720p 중 선택하며 기본값은 480p입니다. 다운로드 화질에는 영향을 주지 않습니다.
- 대체 플레이어를 기본으로 사용하며, 설정을 끄면 임베드 플레이어(iframe)를 먼저 사용합니다. 준비 실패와 임베드 오류에서는 플레이어를 한 번 전환합니다.
